📊 Database Schema

Here's the complete database structure:

Users Table

users.sql CREATE TABLE users ( id UUID PRIMARY KEY DEFAULT uuid_generate_v4(), email VARCHAR(255) UNIQUE NOT NULL, password_hash VARCHAR(255) NOT NULL, name VARCHAR(255), plan VARCHAR(50) DEFAULT 'free', -- free, ai, hybrid, full subscription_status VARCHAR(50) DEFAULT 'inactive', stripe_customer_id VARCHAR(255), created_at TIMESTAMP DEFAULT NOW(), updated_at TIMESTAMP DEFAULT NOW() );

Projects Table

projects.sql CREATE TABLE projects ( id UUID PRIMARY KEY DEFAULT uuid_generate_v4(), user_id UUID NOT NULL REFERENCES users(id), business_name VARCHAR(255), niche VARCHAR(255), target_audience TEXT, description TEXT, website_content JSONB, -- stores generated website copy email_templates JSONB, -- stores email sequences legal_docs JSONB, -- terms, privacy, contracts status VARCHAR(50) DEFAULT 'draft', -- draft, active, archived created_at TIMESTAMP DEFAULT NOW(), updated_at TIMESTAMP DEFAULT NOW() );

Chat Messages Table

chat_messages.sql CREATE TABLE chat_messages ( id UUID PRIMARY KEY DEFAULT uuid_generate_v4(), project_id UUID NOT NULL REFERENCES projects(id), user_message TEXT NOT NULL, ai_response TEXT NOT NULL, created_at TIMESTAMP DEFAULT NOW() );

Subscriptions Table

subscriptions.sql CREATE TABLE subscriptions ( id UUID PRIMARY KEY DEFAULT uuid_generate_v4(), user_id UUID NOT NULL REFERENCES users(id), plan_type VARCHAR(50), -- ai, hybrid, full amount_pence INTEGER, -- store in pence for accuracy stripe_subscription_id VARCHAR(255), status VARCHAR(50) DEFAULT 'active', -- active, cancelled, past_due current_period_start TIMESTAMP, current_period_end TIMESTAMP, created_at TIMESTAMP DEFAULT NOW() );

🔌 API Endpoints

These are the main endpoints you'll need to build:

POST /api/auth/signup

Create new user account

Body: { email, password, name }

Response: { user, token }

POST /api/auth/login

Login user

Body: { email, password }

Response: { user, token }

POST /api/chat/message

Send message to AI chatbot

Body: { projectId, userMessage }

Response: { aiResponse, updatedProject }

POST /api/generate/website

Generate website copy

Body: { projectId }

Response: { websiteContent }

POST /api/generate/email

Generate email templates

Body: { projectId }

Response: { emailTemplates }

POST /api/payments/checkout

Create Stripe checkout session

Body: { planType, email }

Response: { checkoutUrl }

POST /api/webhook/stripe

Handle Stripe webhook

Body: Stripe webhook event

Response: { status: 'received' }

⚡ Performance & Security Tips

Security: Use JWT for auth, hash passwords with bcrypt, validate all inputs, use HTTPS only, implement rate limiting, sanitize user input before storing.
Performance: Cache OpenAI responses, use database indexes, implement pagination, optimize images, use CDN for static files, implement request queuing for AI calls.
OpenAI Costs: Monitor API usage! Set usage limits in OpenAI dashboard. Implement caching to avoid duplicate requests. Start with GPT-3.5-turbo for cost, upgrade to GPT-4 later if needed.
